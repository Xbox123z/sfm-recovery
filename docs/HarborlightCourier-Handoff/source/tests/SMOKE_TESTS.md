# 自动烟测覆盖

运行 Godot Mono 主场景时传入 `--smoke-test` 会执行规则检查并以非零状态退出失败。检查项：

1. 关卡数固定为 2；Easy 为 3 件包裹/1 名巡逻，Hard 为 4 件/2 名巡逻。
2. 包裹仅可领取一次，非法目标被拒绝；完整路线结算奖金正确。
3. Quiet Soles 升级扣款正确；满察觉值本身不会触发失败；明确的 caught 事件才返家、清空当局收益。
4. Hard 失败后可重新开始；完整 Hard 路线奖励和通关标记正确。
5. JSON 存档恢复钱包、升级与通关记录。
6. 墙体阻挡玩家移动和 NPC 视线，开放路径仍可通过。

Smoke tests 验证规则与几何判定，不等同 Windows 原生运行或 Android 真机安装/触控验收。实际平台包的静态校验和运行限制会分别记录在 `verification/`。
